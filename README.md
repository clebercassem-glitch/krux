# KRUX Tecnologia - Site

Site estático pronto para publicação em GitHub Pages.

## Como publicar no GitHub Pages

1. Use o repositório `clebercassem-glitch/krux`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. O workflow em `.github/workflows/pages.yml` publica a branch `main`.
4. Aguarde o GitHub Actions finalizar o deploy.
5. A URL esperada é `https://clebercassem-glitch.github.io/krux/`.
